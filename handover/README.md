# AMBIKA JEWELS — HANDOVER MASTER DIRECTORY

Welcome to the Ambika Jewels handover documentation suite.

To ensure smooth operations and avoid overwhelming non-technical store managers, this folder is strictly separated into two distinct tracks:

---

## 🛍️ 1. Store Owner & Shopkeeper Operating Track (`handover/owner/`)
*Designed for non-technical jewellery business owners and showroom staff. No coding, database, or API knowledge required.*

- **[OWNER_MANUAL.md](file:///d:/Client%20Projects/Ambika%20Jewels/handover/owner/OWNER_MANUAL.md)**: Comprehensive illustrated manual for the daily management of products, photographs, pricing, coupons, orders, invoices, and website notices.
- **[SHOPKEEPER_QUICK_START.md](file:///d:/Client%20Projects/Ambika%20Jewels/handover/owner/SHOPKEEPER_QUICK_START.md)**: 5-minute quick-start cheat sheet for daily showroom tasks.
- **[DAILY_OPERATING_CHECKLIST.md](file:///d:/Client%20Projects/Ambika%20Jewels/handover/owner/DAILY_OPERATING_CHECKLIST.md)**: Morning showroom opening, mid-day sales, and evening closing operational checklist.

---

## 🔐 2. Technical, Security & Infrastructure Track (`handover/technical/`)
*Designed for technical founders, DevOps engineers, and future software developers.*
